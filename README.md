# 🍅 Pomodoro Timer

A modern, responsive Pomodoro Timer web application designed to help users manage work sessions and break intervals effectively using the Pomodoro Technique.

---

## 🚀 Features

* **Timer Controls**: Easily start, pause, and resume work sessions or breaks.
* **Session Tracking**: Displays current session type (*Work*, *Short Break*, *Long Break*) and tracks completed work sessions.
* **Custom Configuration**: Default intervals set to 25 minutes (Work), 5 minutes (Short Break), and 15 minutes (Long Break after 4 sessions).
* **Audio Notifications**: Plays a sound alert whenever a session ends.
* **Responsive Design**: Fully accessible and optimized for mobile, tablet, and desktop viewports.
* **Accessibility (a11y)**: Built with proper ARIA attributes, semantic elements, and full keyboard navigation support.

---

## 🛠️ Tech Stack

* **HTML5**: Semantic document structure and accessibility landmarks.
* **CSS3**: Responsive layouts using Flexbox/Grid and custom properties for styling.
* **JavaScript (ES6+)**: Core timer logic, state management, and DOM manipulation.

---

## ⚙️ Requirements & Rules

1. **Work Session**: 25 minutes
2. **Short Break**: 5 minutes
3. **Long Break**: 15 minutes (triggered automatically after every 4 completed work sessions)
